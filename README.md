# GetTask Analytics Dashboard

KPI-дашборд для мониторинга ключевых метрик бизнеса GetTask с интеграцией Google Sheets.

## 📊 Описание проекта

GetTask Analytics Dashboard — это интерактивный веб-дашборд для отслеживания ключевых показателей эффективности (KPI) маркетинга и продаж. Дашборд загружает данные из Google Sheets в режиме реального времени, визуализирует их с помощью графиков и таблиц, и предоставляет быстрый анализ состояния бизнеса через систему Health Score.

### Основные возможности:
- 📈 11 ключевых метрик бизнеса (выручка, платежи, средний чек, CAC, маркетинговый бюджет, лиды, демо, конверсии)
- 🎯 Сравнение план/факт с процентом выполнения
- 📊 Воронка продаж с визуализацией этапов
- 💰 Таблица маркетинговых каналов с детализацией по бюджетам и результатам
- 🏥 Health Score — общая оценка состояния бизнеса
- 📅 Переключение между периодами (месяцы)
- 🔄 Обновление данных в реальном времени из Google Sheets
- 💾 Кэширование в localStorage для оффлайн-работы

## 🎯 Функциональность

### KPI Метрики
Дашборд отображает 11 ключевых метрик:

1. **Выручка (Revenue)** — общий доход за период
2. **Платежи (Payments)** — количество оплаченных продаж
3. **Средний чек (Avg Price)** — средняя стоимость продажи
4. **CAC (Customer Acquisition Cost)** — стоимость привлечения одного клиента
5. **Маркетинговый бюджет** — общие расходы на маркетинг
6. **Лиды (Leads)** — количество полученных лидов
7. **Демо запланировано (Demos Scheduled)** — количество назначенных демонстраций
8. **Демо завершено (Demos Completed)** — количество проведенных демонстраций
9. **Конверсия лид→демо** — процент лидов, записавшихся на демо
10. **Конверсия демо→завершение** — процент назначенных демо, которые были проведены
11. **Конверсия демо→оплата** — процент проведенных демо, завершившихся продажей

### Воронка продаж
Визуализирует путь клиента от лида до оплаты:
- Лиды → Демо назначено → Демо проведено → Оплата
- Отображает количество на каждом этапе и процент конверсии

### Таблица каналов
Детализация по маркетинговым каналам:
- Название канала и иконка
- Бюджет канала
- Количество лидов
- Количество платежей
- CAC канала (бюджет / платежи)

### Health Score
Автоматическая оценка состояния бизнеса:
- 🟢 **Здоровый (80-100%)** — большинство метрик выполняются на 80%+
- 🟡 **Требует внимания (50-79%)** — есть проблемные области
- 🔴 **Критическое состояние (<50%)** — серьезное отставание от плана

## 🏗️ Архитектура

### Технологический стек
- **Vanilla JavaScript (ES6+)** — без фреймворков для максимальной производительности
- **Chart.js 3.9.1** — библиотека для графиков и визуализаций
- **PapaParse 5.4.1** — парсинг CSV данных из Google Sheets
- **Google Sheets API (публичный доступ)** — источник данных
- **localStorage API** — кэширование данных для оффлайн-работы

### Система загрузки данных
Трехуровневая система с fallback:

1. **Live данные** — загрузка CSV через CORS прокси из Google Sheets
2. **localStorage кэш** — сохраненные данные с timestamp
3. **Hardcoded fallback** — встроенный кэш на случай полного отказа

### CORS прокси
Используется ротация между 4 прокси-сервисами:
```javascript
const CORS_PROXIES = [
    'https://api.allorigins.win/raw?url=',
    'https://corsproxy.io/?',
    'https://api.codetabs.com/v1/proxy?quest=',
    'https://thingproxy.freeboard.io/fetch/'
];
```

При ошибке загрузки автоматически переключается на следующий прокси.

## 🔧 Устранение неполадок

### Проблема: Данные не загружаются

**Симптомы:**
- Индикатор статуса показывает "Кэш" или "Оффлайн"
- Данные не обновляются при нажатии кнопки Обновить
- В консоли ошибки CORS или 429

**Решения:**

1. **Проверьте доступ к Google Sheets:**
   ```bash
   # Попробуйте открыть URL напрямую (замените GID):
   https://docs.google.com/spreadsheets/d/10BPjt5TsaJLpIrLqvyMgEeUsSV4baa4NrGullTsB7AI/export?format=csv&gid=1225075948
   ```
   Если файл не скачивается — проверьте права доступа к таблице (должна быть "Доступно всем, у кого есть ссылка").

2. **CORS прокси недоступны:**
   - Откройте DevTools → Console
   - Проверьте сообщения "Попытка X/4"
   - Если все 4 прокси не работают — используется fallback-кэш (это нормально)
   - Попробуйте обновить позже

3. **Превышен лимит запросов (429 Too Many Requests):**
   - CORS прокси имеют rate limits
   - Подождите 5-10 минут
   - Используйте кнопку "Обновить" реже

### Проблема: Неправильные данные

**Симптомы:**
- Метрики показывают неожиданные значения
- Каналы отображаются неправильно
- Проценты выполнения некорректны

**Решения:**

1. **Проверьте структуру Google Sheets:**
   - Метрики должны быть в строках 2-12
   - Каналы должны начинаться со строки 15
   - Убедитесь, что столбцы B (План) и C (Факт) заполнены

2. **Очистите localStorage:**
   ```javascript
   // Откройте DevTools → Console и выполните:
   localStorage.clear();
   location.reload();
   ```

3. **Проверьте формат данных:**
   - Числа должны быть без пробелов (❌ "25 000", ✅ "25000")
   - Конверсии должны быть десятичными (❌ "40%", ✅ "0.4")

### Проблема: Новый период не отображается

**Симптомы:**
- Добавили новый период, но его нет в селекторе
- При выборе периода ничего не происходит

**Решения:**

1. **Проверьте формат ключа:**
   - Ключ должен быть `'YYYY-M'` (БЕЗ ведущего нуля)
   - Ключ в SHEETS_CONFIG, HTML selector и CACHED_DATA должны совпадать

2. **Проверьте GID:**
   - GID должен быть числом (или строкой с числом)
   - Скопируйте GID из URL Google Sheets

3. **Очистите кэш браузера:**
   - Ctrl+Shift+R (Windows/Linux) или Cmd+Shift+R (Mac)
   - Или откройте в режиме инкогнито

### Проблема: Графики не отображаются

**Симптомы:**
- Вместо графиков пустое место
- Ошибки в консоли связанные с Chart.js

**Решения:**

1. **Проверьте подключение Chart.js:**
   - Откройте DevTools → Network
   - Убедитесь, что `chart.js` загрузился (статус 200)
   - Если нет — проверьте интернет-соединение

2. **Проверьте canvas элементы:**
   - В HTML должны быть элементы `<canvas id="planFactChart">` и `<canvas id="trendChart">`

### Проблема: Health Score некорректный

**Симптомы:**
- Health Score показывает 🟢 при плохих результатах
- Или наоборот — 🔴 при хороших

**Решения:**

1. **Health Score рассчитывается на основе процента выполнения всех метрик:**
   ```javascript
   score = средний процент выполнения всех 11 KPI
   🟢 Здоровый: 80-100%
   🟡 Требует внимания: 50-79%
   🔴 Критическое: <50%
   ```

2. **Проверьте метрики с очень высоким/низким процентом:**
   - Конверсии могут давать >1000% если факт намного превышает план
   - Это искажает Health Score — пересмотрите планы в Google Sheets
